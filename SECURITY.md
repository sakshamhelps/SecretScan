# Security Policy

## Supported versions

Only the latest released version of SecretScan receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately using GitHub's "Report a vulnerability" feature on the
repository's Security tab, or email: `byrex.me@proton.me`.

Include steps to reproduce, affected version and potential impact. We aim to
acknowledge reports within 7 days.

## Scope notes

SecretScan runs locally, makes no network requests and sends no telemetry.
